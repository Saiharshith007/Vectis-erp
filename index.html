Company Header

This metadata is printed on generated PDF documents as the letterhead.

Field Usage

  • Header Address: Printed at the top-left of PDFs.
  • Logo: Printed at the top-right of invoices, quotations and POs. A wide PNG with a transparent background looks best.
  • Detailed Address: Full legal address block.
  • Leave fields blank to use the defaults.
Save Paths

Set the local system directories where generated documents and attachments are saved.

Path Guidelines

  • Provide absolute paths (e.g. C:\Vectis\POs).
  • Ensure folder exists and Server has read/write permissions.
  • Different paths can be configured for Domestic and International categories.
